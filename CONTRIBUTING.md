# Contributing

## Branching

- Base branch: `main`
- Use short-lived branches such as:
  - `feat/...`
  - `fix/...`
  - `chore/...`

## Commit format

Use Conventional Commits:

```text
feat(scope): short summary
fix(scope): short summary
chore(scope): short summary
```

## Pull request checklist

- Backend import check passes
- Frontend build passes
- Security implications are documented for command execution changes
- Comments and user-facing text are written in English
